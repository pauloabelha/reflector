# Reflector II 2.1

## Document convention

This document distinguishes three statuses:

- **Implemented** means the behavior exists in the current R2.1/arcade code and
  is covered by executable contracts.
- **Observed** means a live run produced the stated evidence, including
  failures; it does not imply transfer or game competence.
- **Prospective** means an architectural design to implement and test. It must
  not be described as a current capability.

The AR25 evidence in this document is mechanism evidence on a development
game. R2.1 has now executed a mechanic-diverse 25-game public breadth campaign
and repeatedly cleared AR25 level 1, but it has not demonstrated broad
public-game score competence, sealed transfer, or a Kaggle score.

- 132 committed coordinate actions across 17 games;
- 408 exact observation envelopes containing 967 ordered frames, including 64

The final mechanically frozen 80-second-per-game closure pass attempted all 25

breadth, not score competence.

A later 300-second-per-game partial cohort finalized six games with 102
committed actions and one level. AR25 again cleared on committed action 17 via
the same observed prefix:

```text

```

No route or action meaning is encoded in production logic. Public-game names

### Observed generic score-moving repair

The strongest score-linked intervention is command-identity consistency. In a
pre-repair AR25 trace, the executed action was recorded correctly at the outer
boundary but settled against a stale internal command and effect scope. From an
identical 12-action observation prefix, this made the information ranker treat
an unexecuted action as previously used and pivot to ACTION_4; the run remained
scoreless through 27 commits.

The generic repair atomically aligns:

```text
decision action
= selected ActionCommand
= decision-contract command
= ActionPending payload
= executed transition
= settlement command and effect scope
```

After the repair, the same state selected ACTION_3 and cleared on action 17.
Three repaired long-budget traces—targeted, primary breadth, and final-source
realistic-budget—reproduced that same scoring prefix. This is strong paired
evidence that command identity was necessary at that AR25 pivot. It is one-game
evidence, not a general score guarantee.

### Implemented breadth substrate

The campaign also promoted these generic prerequisites:

- deterministic, evidence-grounded `ActionCommand` objects for simple and
  parameterized coordinate actions;
- exact command/payload identity through selection, pending, execution,
  transition, settlement, replay, and causal effect scope;
- ordered observation envelopes that preserve every animation support frame
  and mark one settled successor;
- same-state no-change accounting scoped to the exact command rather than only
  an opaque action ID;
- a bounded natural `GAME_OVER` retry via explicit RESET, preserving level
  score and boundary semantics;
- demand-driven Qwen scheduling, exact context admission with a 2,048-token
  output reserve, and loss-minimized recovery from empty attention frontiers;
- exact batched graph insertion and replay with byte-identical events, state
  hashes, object ordering, pickups, and Qwen turns;
- explicit separation between executable ranking provenance and unauthorized
  advisory R2 rankings;
- score/report recovery from committed timeout and error ledgers, while never
  counting an uncommitted pending action.

On a final frozen G50T oracle, batched replay was 42.25 times faster and Qwen
turn construction 25.32 times faster with exact equality. Larger frozen traces
measured still greater replay gains. In a matched six-game comparison, the
final build queued 18.2% fewer Qwen calls than the primary build while
producing 8.7% more accepted workspace objects. These are runtime and evidence
delivery improvements, not independent score gains.

### Current evidence boundary

Mechanic access is no longer the best explanation for low score. The dominant
observed boundary is converting exact interventions and successors into

The shadow-only click audit classified the 132 primary click successors as 56

### Deep explanation consolidation

Consolidation is a first-class R2 stage, distinct from ordinary per-action
semantic refresh. R2.1 now exposes this generic reflective-abstraction
operation to Semantic Qwen.
A level completion is its first implemented trigger, not its ontology. At that
boundary, ordinary action pressure stops: the completed evidence is frozen,
one synchronous deep Qwen turn runs, and successor control remains blocked
until the compiler accepts either reusable abstractions or an explicit
abstention. The operation can later run over any bounded set of sufficiently
settled explanations: a partial attempt, several attempts, or recurring
structures within one episode.

```text
LEVEL n CONTROL
→ committed completion boundary
→ freeze the canonical completed-context interval
→ deterministic R2 consolidation digest
→ dedicated deep Qwen reflection
→ compile one to three abstractions, or explicit abstention
→ persist game-scoped ungrounded reusable R2 schemas
→ reset situated state
→ project schemas into level n+1 as fresh binding questions
→ predict and settle
→ confirm, specialize, accommodate, or reject
```

The request asks a narrow abductive-compression question: what are the smallest
useful R2 schema fragments that could have generated the settled structures
after nuisance detail is quotiented out? It explicitly asks which structures
persisted, which causal regularities survived intervention, which explanations
contributed to completion, which alternatives were refuted or context-bound,
and which details can be forgotten without losing falsifiable predictions. It
does not ask what was learned about a named game or which action should occur
next.

The retrospective source covers the complete canonical revision interval from
the preceding level boundary (or episode start) to the winning boundary. R2
does not serialize that interval as a transcript. Before Qwen, it constructs an
evidence-preserving consolidation digest:

```text
raw settled level history
→ quotient repeated situated explanations by action-free semantic signature
→ preserve occurrence counts and complete-source digests
→ summarize potential traces by endpoints, range, monotonic step counts,
  distinct-value count, and ordered digest
→ retain epistemic status counts and confirmation/refutation/confidence ranges
→ retain initial, status-change, first-confirmation, repeated-confirmation,
  first-refutation, terminal, and latest provenance points
→ aggregate support/refute edges into evidence classes with counts,
  representative endpoints, and ordered-pair digests
→ retain completion evidence and a bounded citation set into the full ledger
```

Compression is therefore performed by deterministic R2 structure, not by
asking Qwen to summarize an oversized history. Multiplicity and provenance
remain auditable; byte-repeated situated detail does not consume the reasoning
window. Explanations with no structured semantic content are retained by count
and digest rather than promoted into apparent abstraction evidence. The
successor context's frame, sparse frontier, deltas, situated objects, and
images are omitted from transport. Earlier levels are excluded from this
packet; their accepted abstractions may persist separately as game-scoped
hypotheses.

This is a dedicated large-reasoning/small-authority operation. Ordinary semantic calls
remain at 2,048 output tokens with a 192-token thinking budget. Consolidation
alone requests a 5,120-token generation envelope with a 1,024-token thinking
budget, leaving roughly 4,096 tokens for the visible structured artifact. The
existing exact 16,384-token admission gate reserves all 5,120 tokens and may
shrink optional frontier material, but it never drops the boundary task or its
mandatory evidence. Qwen may compare several candidates internally; its final
authoritative artifact defaults to one minimal abstraction and is bounded to at
most three only for causally independent structures with distinct reuse
predictions. Duplicate abstraction bodies are rejected.

The first live deep-boundary attempt proved the fail-safe: the uncompressed
retrospective required 46,802 prompt tokens before the 3,072-token reserve, so
R2 queued nothing and blocked level-2 control. Replaying that exact committed
AR25 boundary through the deterministic digest reduces 80 raw explanation
objects to three structured semantic families, records 33 unstructured
explanations by digest only, aggregates 12 judgments into two classes, and
exposes 12 citation pointers. The resulting conservative prompt is about 8,000
tokens; with the earlier 3,072 reserve it occupied about 11,070 of 16,384. The
current 5,120-token envelope still fits that exact packet at about 13,120 tokens
occupied and retains more than 3,200 tokens of admission headroom.

The final live AR25 proof (`arcade-runs/run-1786471943209771871`) used that
profile after the action-17 clear. The dedicated call queued at ledger sequence
421, completed in 35.47 seconds with `finish_reason=stop`, compiled three
accepted workspace objects with no rejection, and integrated before any
successor decision. The first level-2 `ActionDecision` appears only at sequence
436; therefore the boundary gate was observed end to end, not inferred from a
unit fixture.

An accepted `explanation_consolidation` contains one to three action-free goal
proposals mapped one-to-one to typed abstractions. Each may describe
applicability relations, preserved structure, causal shape, predicted reuse,
and counterconditions. Exact duplicate set items are deterministically
quotiented; competing semantic values are not repaired. R2—not Qwen—marks
every declared goal role as an
unresolved fresh-binding port and applies the mandatory nuisance quotient. The
task and transport mark absolute
coordinates, palette values, situated object identity, prior role bindings,
prior empirical support, and prior intervention identity as nuisance; the
compiler rejects a proposal that reintroduces situated detail. Qwen may
abstain; it cannot repair or invent evidence.

Every reusable schema is persisted with
`authority_scope=fresh-binding-probe-only`, empirical support zero, and this
mandatory reset:

```text
schema definition             projects and fresh-binds
empirical support             resets
bindings                      reset
role identities               reset
potentials                    reset
intervention applicability    resets
progress authority            resets
```

This is projection in the cognitive-science sense, not recall of a route.
Contracts show that R2 can use an accepted schema immediately in the new
context: its relational goal, typed roles, observable potential, terminal
condition, applicability relations, and counterconditions constrain fresh
bindings and shadow generation. Whether this actually reduces semantic
rediscovery and improves live control remains an empirical question.

For example, an L-shaped completion followed by a Z-shaped context should not
transfer either letter shape, either palette value, or an opaque action ID.
What may project is the relational diagram shared by both situations:

```text
FitPair(?actor, ?reference)

requires:
    SameOutline(?actor, ?reference)
    DifferentValue(?actor, ?reference)
    UniqueSituatedRoles(?actor, ?reference)

preserves:
    topology(?actor)
    intrinsic_geometry(?actor)

prefers:
    decrease BoundaryGap(?actor, ?reference)

completes_when:
    BoundaryGap(?actor, ?reference) = 0

accommodates:
    which current command controls ?actor
    obstruction and regime conditions
```

The L pair and Z pair are two bindings of this schema, not two separate game
rules. A complementary generic continuation schema may retain a newly
confirmed preferred transition while its role correspondence remains unique
and its residual changes monotonically, then revoke immediately on no-change,
refutation, identity breakage, or completion. This continuation rule never
transfers the prior action ID; it becomes executable only after the new
context confirms a situated command effect.

The anti-overfitting rule is exact: completion does not license carrying an
answer forward; it licenses carrying a typed question. Schema definitions may
persist, but empirical support, bindings, identities, potentials, action
applicability, and progress authority do not. The successor inherits a
schema-shaped search space and must earn correspondence and mechanism anew.

What does not transfer is the claim that an old command still has the same
effect on the newly bound roles. For a consolidated schema, the effect model
consults only evidence acquired in the current context. Existing game-scoped
effects remain auditable but cannot by themselves make that schema
`PROGRESS_ELIGIBLE`. The first projected use is a schema-informed mechanism
probe; a fresh successor accommodates, specializes, confirms, or refutes the
projection. Once the new context supports the mechanism, the already-projected
goal can become progress-authoritative without relearning the explanation.

At the AR25 diagnostic boundary this pass was scheduled after the action-17
winning transition and its graph evidence were durable, before the first
level-2 action.
It is intentionally unable to encode the observed `1, 2×11, 3×5` route,
coordinates, colors, bindings, or action meanings. This implementation has
contract and integration coverage. A live diagnostic verified the boundary
placement and completed-context-only transport, but its original broad
working-note response was first rejected and later responses were truncated
because the old call used ordinary output limits and re-emitted ordinary
aliases and abductive material. A first digest-based deep response then fit the
prompt but exhausted its 3,072-token generation envelope; the next complete
response exposed redundant Qwen ownership of authority-reset fields. Both
failures blocked level 2. The production contract is now a deliberate
deep boundary phase: a complete level-scoped R2 consolidation digest, a dedicated
5,120/1,024 request profile, one compact schema by default (up to three only
for causally independent structures) mapped one-to-one to its goal, or an empty
abstention. Invalid transport or compilation cannot
open successor control, and the mandatory boundary call is not suppressed by
the ordinary per-episode call cap.

The final live response proposed one generic `fit/align(actor,target)` schema:
suggested same-outline and same-interior applicability, decreasing
`fit_residual` toward contact, preserved contact state, a `changes_contact`
causal hypothesis, and `mechanism_conflict` as a countercondition. R2 persisted
it with empirical support zero, both roles unresolved, and
`fresh-binding-probe-only` authority. In the first level-2 decision it freshly
bound the new actor/target pair, reported both identities `UNINITIALIZED`, the
mechanism `UNKNOWN`, model support false, and predicted progress null. Action 4
was consequently a `PROBE_ELIGIBLE` information probe, not transferred
progress authority. This demonstrates live consolidation and abstract
projection. It does not yet demonstrate a level-2 clear or a score gain.

The resulting learning cycle is deliberately Piagetian without changing R2's
ontology:

```text
within context: assimilation → anticipation → action → settlement
at boundary:    comparison → reflective abstraction
new context:    attempted assimilation through fresh binding
on failure:     accommodation or rejection
on recurrence:  confirmation and eventual promotion
```

## Architectural principle

R2.1 uses one recursively compositional schema language.

> Schemas provide the grammar of possible structure and mechanism. Verbs
> provide the grammar of preferred change. Explanations are situated,
> executable compositions written in that language.

Verbs, explanations, goals, and skills are not separate planning ontologies
bolted onto a perceptual schema engine. They are higher-order schema bindings
whose inputs may themselves be schema bindings.

The representational progression is open-ended:

```text
observational support
→ structural bindings
→ relational bindings
→ configurations
→ potentials
→ verbs
→ causal effects
→ progress
→ explanations
→ schemas over explanations
→ skills
→ ...
```

There is no fixed architectural level ceiling. Each fitting cycle is bounded,
but a binding produced at one level is a typed atom available to later schemas.

## One schema language, different orientations

All of the following are schemas. Their difference is epistemic role, not
representation type.

| Orientation | What it constrains |
|---|---|
| Descriptive | What structures can coexist |
| Correspondence | What structures count as the same or different under an invariant |
| Causal | What successor structure follows an intervention |
| Potential | What measurable state belongs to a situated relation |
| Verb | What transformations count as progress |
| Preferred completion | What unresolved successor would satisfy a verb |
| Progress | What causal binding realizes a preferred completion |
| Explanation | What situated structural, telic, and causal bindings cohere |
| Skill | What reusable causal composition realizes a verb over several steps |

## Schemas

A schema is a reusable intensional definition containing typed ports,
relational constraints, component schema IDs, an output type, and an epistemic
orientation.

For example:

```text
SameOutline(?left, ?right)
```

is reusable. A binding such as:

```text
SameOutline(blue_L, yellow_L)
```

is situated. Complete bindings become typed workspace atoms, allowing higher
schemas to bind them recursively.

Incomplete bindings are retained rather than discarded. Every unresolved
constraint projects a **shadow**: an explicit question about a possible
completion. Environment evidence can later reify or refute that shadow.

## Verbs

A verb is a schema over preferred transformations. It is not an environment
action, policy, reward label, or English instruction.

Conceptually, a verb contains role ports, structural admissibility constraints,
a grounded potential, an ordering over successor potentials, and a terminal
completion class.

For example:

```text
FIT(?actor, ?target)

requires:
    SameOutline(actor, target)
    SameInterior(actor, target)
    DifferentValue(actor, target)

potential:
    FitResidual(actor, target)
    = BoundaryGap(actor, target) + OverlapDeficit(actor, target)

preferred completion:
    successor deficit < current deficit

terminal:
    deficit = 0
```

The verb does not specify which action realizes that completion. The same FIT
schema may join with different learned causal bindings in different games.

### Canonical residual convention

R2.1 expresses telic quantities as residuals whenever possible. Progress
normally decreases a residual toward its minimum.

```text
FIT      → decrease fit_residual
TOUCH    → decrease boundary_gap
ALIGN    → decrease centroid_distance
CONTAIN  → decrease containment_violation
MATCH    → decrease symmetry_residual
```

This removes avoidable sign ambiguity. Raw overlap is not used as a FIT
potential because “increase overlap” and “decrease non-overlap” encode the same
order with opposite signs. `overlap_deficit` alone is flat before contact, so
FIT uses the compositional potential
`fit_residual = boundary_gap + overlap_deficit → 0`. It rewards approach while
the figures are separated and overlap completion after contact.

## Goals

Goal is derivative rather than primitive. A grounded verb already supplies
current situated roles, current potential, preferred order, and terminal
completion.

The goal exposed by an explanation is the active verb's situated terminal:

```text
FIT(blue_L, yellow_L)
terminal: fit_residual(blue_L, yellow_L) = 0
```

R2 contains no game-specific “put the blue object on the yellow object” goal
schema. A semantic model may propose FIT; only R2 may decide whether FIT
coherently binds the current workspace.

### Implemented semantic-to-control loop and global-objective boundary

The current implementation joins conceptualization and situated control through
two different workspace products from the configured semantic model:

```text
model_scratchpad
    fluid five-field semantic state for the model and Arcade

workspace_write.goal_proposals
    reusable action-free verb schemas for R2 to validate and bind

workspace_write.abductive_compositions
    typed compositions over stable schema definitions for R2 to compile
```

R2 consumes the structured proposals, not the scratchpad prose, when ranking an
action. For every admissible goal proposal it attempts to bind abstract verb
roles to current entities, measure the proposed potential, join the grounded
verb to a supported causal effect, and construct a situated explanation with a
falsifiable successor prediction. Ranking then uses the following hard gate:

```text
PROGRESS_ELIGIBLE
    supported mechanism + unique identities + positive predicted verb progress
>
PROBE_ELIGIBLE
    an unresolved mechanism with an explicitly discriminating successor
>
INELIGIBLE
```

Every authorized action is still observed and settled. Confirmations,
refutations, grounded roles, open shadows, and competing explanations return to
the semantic model through the bounded `r2_semantic_projection`. Explanation
consolidation can subsequently propose smaller reusable schemas with zero
inherited empirical authority; those schemas must bind and earn support again.
This is the implemented conceptualization/control loop:

```text
abduce a concept or composition
→ propose an action-free verb
→ R2 grounds its roles and potential
→ join it to a causal mechanism
→ lock control to one situated executable explanation
→ act once
→ settle the prediction
→ preserve, revise, consolidate, or reject
```

The phrase **lock control** above describes R2's current internal control
eligibility, pending prediction, and bounded fast-path authorization. It is not
yet a first-class shared `explanation_lock` object. The semantic scratchpad can
therefore remain more tentative or abstract than R2's currently active
situated explanation.

The exact scratchpad object is:

```text
model_scratchpad = {
    game_objective,
    explanation,
    goal,
    expectation,
    notes
}
```

It is passed back to later semantic turns and reflected as-is in Arcade after
canonical validation. It is deliberately unverified and is not compiled as a
workspace claim. In particular, `game_objective` records the model's current
inference about winning or completing the game, but neither it nor the prose
`objective_hypothesis` currently participates directly in R2 action ranking.
Only accepted structured `goal_proposals` and `abductive_compositions` enter
that control path.

Consequently, R2 currently has a strong testable connection from a situated
verb to **local residual progress**, but only an inferred semantic connection
from that residual to **beating the game**. Decreasing `fit_residual`, for
example, is not by itself evidence that completing FIT will clear a level. A
completion boundary can retrospectively support that connection, but the
controller does not yet represent it prospectively as a causal goal graph.

The intended prospective completion is a structured, evidence-cited
`goal_contract` containing terminal observables, open/refuted completion
hypotheses, and subgoal links from verb completions to the game objective. Each
goal proposal would declare its hypothesized contribution and falsification
conditions. A first-class `explanation_lock` would separately identify the
current situated explanation, verb binding, roles, residual, support,
refutations, status, and explicit unlock conditions. Neither object is
implemented yet; prompt prose must not be mistaken for either contract.

## Executable explanations

An explanation is not fundamentally an English sentence. It is a coherent,
situated, higher-order binding graph composed from structure, telos, mechanism,
and prediction.

```text
Explanation E17

bindings:
    actor  → Shape(blue_L)
    target → Shape(yellow_L)

schemas:
    SameOutline(actor, target)
    SameInterior(actor, target)
    DifferentValue(actor, target)

verb:
    FIT(actor, target)

potential:
    fit_residual = 40
    preferred successor < 40
    terminal = 0

causal effect:
    ACTION_4 translates actor right

progress:
    ACTION_4 realizes a preferred FIT completion

prediction:
    fit_residual 40 → 37
```

This graph is executable because it connects a desired transformation to a
learned causal morphism and makes a falsifiable one-step prediction.

The explanation itself has output type `explanation-binding`. Higher schemas
can therefore consume explanations normally:

```text
SameStrategy(E1, E2)
FirstAcquireThenFit(E1, E2)
```

Repeated successful compositions may later be abstracted into reusable skill
schemas without introducing a separate hierarchy mechanism.

### Generative explanation invariant

R2 distinguishes a descriptive binding from an explanation by empirical risk,
not by linguistic richness or schema depth.

```text
schema + situated binding
→ descriptive hypothesis

schema + situated binding + constrained completion beyond current support
→ projected shadow
→ explanation binding
```

The normative invariant is:

```text
ExplanationBinding(E_t)
⇒ at least one non-vacuous projected shadow beyond support_t
```

A plausible Qwen interpretation is therefore not yet an explanation. It
becomes explanatory only when R2 compiles it into a situated higher-order
binding whose unresolved frontier constrains future empirical completion.
`OPEN` is permitted; unconstrained is not. An open projection must identify
which ports remain unresolved and what observation would reify, refute, or
discriminate their possible completions.

Projection is not a second prediction ontology. It is ordinary recursive
diagram completion over an ordered empirical boundary:

```text
support_t
↓
ExplanationBinding(E_t)
↓ fit a partial higher-order binding across t and t+1
SuccessorShadow(?support_t+1)
```

The missing successor support is not evidence. It remains a shadow until the
environment supplies the next ordered observation. Projection operates at the
same representational level as its explanation:

```text
structural explanation
→ persistence, correspondence, appearance, disappearance, or structural change

causal explanation
→ intervention-conditioned successor structure

telic explanation
→ an order over successor potentials or a terminal completion

consolidated explanation
→ structure expected to become freshly bindable, measurable, or falsifiable
```

An explanation projects a bounded set of ordinary alternative completions,
not hard-coded semantic outcomes such as `success` or `failure`:

```text
SuccessorShadow

applicability:
    conditions under which this completion can bind

preserves:
    bindings or relations expected to remain invariant

changes:
    bindings or relations expected to differ

potential orientation:
    decreased | increased | stable | terminal | open

diagnostic consequence:
    competing explanations or mechanisms distinguished by this completion

open ports:
    remaining structure not constrained by current support
```

Terms such as preferred, adverse, stable, or identity-broken are later
interpretations of fitted successor diagrams. They are not primitive branch
labels and receive no authority before settlement.

Prediction width follows epistemic state. A supported mechanism produces a
narrow action-conditioned shadow. A contested mechanism produces several
observable alternatives. An unknown mechanism is explanatory only when its
alternatives distinguish candidate causal completions—for example actor
changes while target persists, target changes while actor persists, or the
relevant bindings remain stable. Missing grounding exposes typed open ports
and the evidence required to complete them. A null predicted value plus an
unconstrained question is descriptive uncertainty, not yet an explanation.

The primitive horizon is exactly one empirical support:

```text
E_t
→ {Shadow_t+1^1 ... Shadow_t+1^k}
→ execute one ActionCommand
→ observe O_t+1
→ settle projected completions
→ accommodate E_t+1
→ project again
```

R2 does not ordinarily materialize a deep speculative rollout tree. Deeper
anticipation emerges recursively from bind, project, settle, and rebind.
Supported causal morphisms may later compose internally for planning, but the
epistemic primitive remains one explanation, one bounded successor frontier,
and one environmental settlement.

An executable explanation must expose this frontier before authorizing an
intervention. The chosen action cites the explanation-relative completion it
is intended either to realize or discriminate. Settlement may reify a
completion, refute it, leave it unresolved, break a required correspondence,
refute mechanism applicability, or refute the explanation itself. These are
ordinary support/refutation relations over bindings; no prediction truth store
is added.

This also strengthens consolidation. Deep reflection abstracts not merely the
structure that survived, but the generative projection that survived:

```text
settled situated explanations
→ reusable higher schema H
→ partial fresh instantiation of H
→ RegroundingShadow(new context)
```

A consolidated FIT schema may project that compatible roles should freshly
bind, a residual should become measurable, and a terminal minimum should be
definable. It does not project which objects fill the roles, which command
controls them, which direction realizes progress, or whether a situated prior
mechanism transfers. Within-context successor prediction and cross-context
regrounding are therefore two uses of the same generative-completion mechanism;
only their unresolved ports differ.

Explanation quality becomes measurable:

```text
projection coverage
    interventions preceded by a non-vacuous explanation projection

projection calibration
    observed successors contained by projected alternatives

discrimination
    reduction of live competing completions after settlement

falsification value
    failed projections that trigger meaningful accommodation

compression
    situated detail discarded while projection quality survives

cross-context generativity
    consolidated projections that freshly bind and survive settlement
```

The stronger definition is:

> **An R2 explanation is a situated higher-order schema binding whose fitted
> structure entails at least one non-vacuous shadow beyond its present
> empirical support.**

Schemas become explanations when their situated bindings cast falsifiable
shadows. Explanation is generative structure under empirical risk.

## Current recursive binding chain

The R2.1 adapter materializes this first-class chain:

```text
region-binding
    ↓ structural relations
verb-role-binding
    ↓ MeasuresPotential
potential-binding
    ↓ AdmissibleVerb
verb-binding
    ↓ unresolved PreferredCompletion
preferred-completion shadow
```

Once a learned action effect can project a successor potential:

```text
action-binding
+ current potential-binding
+ prospective-potential-binding
    ↓ ProjectsPotential
causal-effect-binding

causal-effect-binding
+ reified preferred-completion-binding
    ↓ RealizesPreferredCompletion
progress-binding

verb-binding
+ causal-effect-binding
+ progress-binding
    ↓ CoherentSituatedExplanation
explanation-binding
```

A preferred-completion shadow remains open while the causal mechanism is
unknown. A positive projected successor supplies the missing completion fact,
reifies the shadow, and permits Progress and Explanation schemas to bind.

## Epistemic lifecycle of a verb

The system must never conflate semantic suggestion with empirical control.

```text
PROPOSED
    Qwen supplied a candidate reusable telic schema.

REJECTED
    Its contract is malformed, its order is incoherent, its structural
    constraints cannot bind, or its potential is not measurable.

GROUNDED
    R2 bound its roles and present potential, but the realizing causal
    mechanism may remain open.

ACTIVE
    R2 joined the grounded verb to a causal-effect binding and a positive
    Progress binding. It can control the next action.

CONFIRMED / REFUTED
    The observed successor agreed or disagreed with the one-step prediction.
```

Only GROUNDED and ACTIVE verbs may appear as used by the current explanation.
Raw Qwen proposals remain explicitly proposed; rejected proposals retain their
reason.

## Perception and categorical fitting

For every displayed frame, R2 extracts weak, inspectable region descriptions:

```text
value/color code
area
normalized interior layout
outline/envelope
hole count
centroid
occupied cells
```

It derives symmetric relational facts such as:

```text
SameOutline / DifferentOutline
SameInterior / DifferentInterior
SameValue / DifferentValue
SameArea / DifferentArea
AlignedHorizontal / AlignedVertical
Touches / Disjoint
```

These facts support many bindings in parallel. The schema workspace can retain
equivalent, competing, partial, and overlapping categorical organizations
under explicit frontier budgets. The current region extractor, however, still
begins from one four-connected-component factorization. Maintaining genuinely
competing segmentations is a required control improvement described below.

Frame-local levels commonly begin as:

```text
L0  region bindings
L1  relation and role bindings
L2  configurations and potentials
L3  verbs and causal effects
L4+ preferred completions, progress, explanations, and later compositions
```

These are observed depths, not hardcoded architectural meanings.

### Dynamic spatial schemas across frames

R2 should treat spatial structure as continuously updated situated bindings,
not as prose labels recreated independently on every frame. Reusable schemas
remain context-free definitions:

```text
BoundaryGap(?a, ?b)
CentroidDistance(?a, ?b)
RelativePosition(?a, ?b)
LeftOf(?a, ?b)
Above(?a, ?b)
AlignedHorizontal(?a, ?b)
AlignedVertical(?a, ?b)
Touches(?a, ?b)
Overlaps(?a, ?b)
ContainedBy(?a, ?b)
```

A frame supplies their situated values and evidence:

```text
frame 17:
    BoundaryGap(blue_L, yellow_L) = 11

frame 18:
    BoundaryGap(blue_L, yellow_L) = 8
```

Entity correspondence links those two bindings. Higher temporal schemas then
fit the change:

```text
Approaching(?a, ?b):
    BoundaryGap_t+1(?a, ?b) < BoundaryGap_t(?a, ?b)

Receding(?a, ?b):
    BoundaryGap_t+1(?a, ?b) > BoundaryGap_t(?a, ?b)

StableDistance(?a, ?b):
    BoundaryGap_t+1(?a, ?b) = BoundaryGap_t(?a, ?b)

Touching(?a, ?b):
    BoundaryGap(?a, ?b) = 0
```

`Close` must not be a universal Boolean primitive with an arbitrary pixel
threshold. R2 preserves the raw measure first. A categorical closeness binding
is contextual, scale-aware, and defeasible:

```text
NormalizedGap(a, b) =
    BoundaryGap(a, b)
    / max(CharacteristicSize(a), CharacteristicSize(b), 1)

Close(a, b | scale, interaction, explanation)
```

The same raw distance may therefore support `Close` in one situated
explanation and leave it open in another. Threshold choice is represented as a
condition of the higher schema, never hidden inside perception.

This yields four clean orientations of the same schema language:

```text
structural schemas   what the current spatial configuration is
temporal schemas     how corresponding bindings changed
causal schemas       which observed action produced that change
verbs                which direction of change is preferred
```

An executable explanation composes all four. For example, `FIT(a,b)` may
prefer decreasing `BoundaryGap`, then decreasing `OverlapDeficit`, while an
observed action schema predicts the next situated values.

R2.1 measures centroid distance, boundary gap, overlap deficit, fit residual,
and containment violation, and it fits exact relations including alignment,
touching, and disjointness. It now also constructs bounded typed
correspondences, residual-component bindings, and stable cross-frame
`ResidualDecreased`, `ResidualIncreased`, and `ResidualStable` bindings. These
are comparison bindings, not yet a sufficient object-permanence mechanism.
Persistent identity through duplicate figures, fragmentation, disappearance,
merging, rotation, and deformation remains a central unsolved control problem.

### Categorical comparison and abduction

Comparison is not a separate numerical subsystem and `Close`, `Aligned`, or
`SameStrategy` are not installed as semantic primitives. The existing schema
language is interpreted categorically:

```text
typed workspace atom       object
grounded transformation    morphism
schema                     finite typed diagram
binding                    situated diagram realization
partial binding            partial realization
shadow                     unresolved diagram extension
reified binding            diagram made available as a higher-level object
```

A correspondence between two objects is an ordinary span binding:

```text
       M
      / \
     p   q
    /     \
   X       Y

X ← M → Y
```

`M` records matched typed structure. At the region level it can preserve
boundary or cell structure. At the verb level it can preserve actor, target,
potential, and terminal ports. At the explanation level it can preserve roles,
mechanism, prediction, and completion. Because every reified binding is again
a typed workspace atom, the same construction applies recursively at every
level.

Exact sameness is an isomorphism in a selected projection category. Sameness
modulo translation, value, episode identity, or another nuisance
transformation is an isomorphism after the corresponding projection or
quotient; the ignored structure must remain explicit.

Alignment is diagram commutativity. For a candidate square:

```text
X ─f→ X'
│      │
p      q
│      │
▼      ▼
Y ─g→ Y'
```

exact alignment satisfies:

```text
q ∘ f = g ∘ p
```

Partial alignment retains a typed residual for the disagreement between the
two paths. Residuals are ordinary situated bindings with measure type, raw
value, normalization, evidence, and context. R2 initially preserves a residual
vector rather than hiding a weighting:

```text
geometry
topology
port structure
causal effect
terminal structure
```

Closeness is the enriched hom-value of a comparison, not a Boolean predicate.
A contextually learned `Close` category is a sublevel regime over one or more
explicit residuals. It is promoted only when that cut predicts a causal or
explanatory distinction and survives changes of scale and nuisance features.

Temporal observation supplies morphisms from situated structures at frame
`t` to their correspondents at frame `t+1`. Generic higher schemas bind:

```text
ResidualDecreased
ResidualIncreased
ResidualStable
ResidualReachedZero
ResidualCrossedRegime
```

Semantic labels such as approaching, receding, touching, or aligned may name
these recurring structures later; they never supply their evidence.

Abduction is diagram completion. Semantic Qwen may propose missing objects,
morphisms, port correspondences, commuting-path claims, predicted shadows, and
alternative completions over existing stable schema definitions. R2 compiles
the proposal into ordinary schema definitions and then performs its normal
operations:

```text
canonicalize
type-check sources and targets
fit assignments
project shadows
reify or reject
predict
settle from environment evidence
```

Qwen cannot assert a binding, manufacture evidence, promote a schema, or
select an action. A successful situated completion remains episode-local.
Promotion searches for the least reusable diagram through which repeated
successful instances factor, discarding unnecessary color, coordinate,
identity, and game-specific structure.

#### Efficiency invariants

Recursive comparison must remain attention-bounded:

1. Candidate correspondences are generated only inside compatible type and
   interface buckets.
2. Each atom retains at most a small nearest-neighbor correspondence frontier;
   unrestricted all-pairs fitting is forbidden.
3. Exact structural fingerprints and stable schema IDs are used before any
   more expensive residual evaluation.
4. Per-type and global comparison, residual, shadow, and abduction budgets are
   explicit and reported in telemetry.
5. Residual vectors remain sparse; absent interfaces do not create zero-valued
   pseudo-evidence.
6. Cross-frame comparison uses stable correspondence keys and the immediately
   preceding frame, not an ever-growing history.
7. Qwen composes stable schema IDs, while R2 resolves them to current situated
   bindings. Stale situated IDs cannot silently ground.
8. Abductive diagrams are capped in objects, morphisms, alternatives, and open
   ports before fitting.
9. Caches are episode-local and content-addressed; reset removes all situated
   comparison and abductive state.
10. No categorical binding influences control without a grounded measurable
    potential and an observable successor prediction.

The implementation therefore adds no independent truth store. Correspondence,
residual, temporal orientation, abductive completion, and any later strategy
abstraction must all appear as typed schema definitions or situated schema
bindings in the same recursive workspace.

## Causal learning

Qwen is forbidden from selecting or describing environment actions. R2 learns
command-scoped effects from observed transitions. A command is not only an
action ID: parameterized actions retain exact payload, current-frame grounding,
command ID, and effect-scope ID.

After one intervention, it records grounded effects such as:

```text
ActionCommand(ACTION_4, payload={}, scope=4)
× region_type_A
→ translation(0, +3)

ActionCommand(ACTION_6, payload={x: 20, y: 43}, scope=observed_region_R)
× observed_region_R
→ observed successor footprint
```

For each legal action and grounded verb, R2 projects the learned effect onto
the current actor and target, constructs a prospective successor potential,
and fits a causal-effect binding.

Predictions remain defeasible. The next frame adjudicates the exact pending
explanation and updates confirmation or refutation counts.

## Implemented one-action controller

R2.1 always replans after exactly one external action.

```text
1. Observe the current frame.
2. Fit structural schemas recursively.
3. Read semantic verb proposals.
4. Validate and ground their roles and potentials.
5. Join grounded verbs with learned causal effects.
6. Resolve exactly one legal, currently grounded ActionCommand.
7. Persist the identical command and payload as ActionPending, then execute it.
8. Observe the complete ordered successor envelope and its settled frame.
9. Settle the prediction and projected shadows.
10. Repeat from the new workspace.
```

The ranking order is:

```text
positive predicted progress
>
unknown but decision-relevant information
>
known non-progress
```

Within a class, R2 uses information value, exact-command repeated-no-change
risk, and stable tie-breaking. Observed no-change is retained as evidence. Any
internal action mutation must rebind a command from the current frame; a
parameterized action without an exact grounded payload fails before transport.
The present
implementation does not yet have a sufficiently strong state-dependent
precondition model to guarantee that a blocked action, lost object identity,
or local minimum is diagnosed correctly.

Information-seeking is not a separate planner. It resolves open ports and
competing completions in the same active explanation graph.

### Implemented bounded preferred-policy fast path

R2.1 may temporarily compress repeated full deliberation into a bounded
authorization only after a grounded state-conditioned policy has earned
empirical authority. This is not an open-loop macro and it is not a rule to
repeat one action while a scalar decreases.

```text
FastPathAuthorization

objective:
    grounded situated verb / preferred completion

preferred order:
    P(successor) ≻ P(current)
    # scalar decrease or increase, set inclusion, partial order,
    # terminal transition, or another grounded order

policy:
    π(state) -> one legal action
    # derived only from supported causal effects

protected invariants:
    role identity
    mechanism applicability
    measurable potential

budget:
    at most four authorized actions
    zero tolerated failures
```

The current authorization threshold is two consecutive settlements for the
same generic policy signature with:

```text
prediction confirmed
preferred order strictly advanced
protected invariants held
mechanism confidence >= 0.8
control status = PROGRESS_ELIGIBLE
```

The signature contains the grounded schema, measure, preferred direction,
terminal class, and bounded structural applicability descriptors. It excludes
the chosen action ID, situated binding IDs, coordinates, game identifiers, and
raw palette values. Consequently one authorized policy may select different
action IDs in different states.

Execution still preserves the exactly-one-action invariant:

```text
choose π(current_state)
predict one observable successor
execute exactly one action
observe
settle prediction, preferred order, and invariants

if every check passes and budget remains:
    cheaply authorize the next policy application
else:
    revoke immediately and return to full R2 deliberation
```

Revocation occurs on prediction mismatch, mechanism refutation, identity
ambiguity, invariant failure, non-preferred progress, inapplicable effects,
unresolved objectives, unexpected environment events, level transition, or
bounded-horizon exhaustion. While authorization remains valid, Arcade skips
recursive frame fitting and publishes cached fast-path telemetry; observation
and one-step settlement are never skipped.

In a fresh AR25 trace, this path acquired authority after repeated confirmed
translations, produced strict preferred progress with unique identities and
confirmed mechanisms, and reported `0.0 ms` recursive-fitting time on
authorized turns. It later revoked when a mechanism prediction was refuted.
This is mechanism evidence for bounded policy reuse, not sealed evidence of
transfer to unrelated games.

### Defeasible comparative role grounding

Role grounding is implemented as a generic comparative inference, not as a
special rule for a verb, shape, color, game, or route. `DefeasibleRoleGrounder`
enumerates bounded typed role tuples and retains an explicit evidence vector:

```text
type compatibility residual
structural residual
topology residual
relative-area residual
interior residual
outline residual
spatial-measurability residual
evidence-mass residual
identity-continuity residual
value relation
```

The vector is not collapsed into an opaque learned score. Clearly dominated
tuples are removed by Pareto filtering; at most four remaining situated role
hypotheses proceed to causal evaluation. A fixed rank aggregation orders that
bounded front for deterministic execution and display.

Semantic constraints have explicit modalities:

```text
required | suggested | anti-clue | unknown
```

Only a schema-required relation is a hard gate. Legacy Qwen constraints without
a modality are interpreted as `suggested`. Similarity and Qwen clues can retain
or order a hypothesis but never grant action authority. For example, the
universal implemented definition of FIT requires spatially typed roles and a
measurable `fit_residual`; same outline, same interior, different value, and
similar area are defeasible evidence about a particular binding.

Each retained role tuple has a translation-invariant structural hypothesis ID.
This prevents a moving hypothesis from acquiring a fresh identity every frame.
The current Control v0 may authorize an unknown-mechanism probe for a retained
hypothesis. Progress authority still requires unique post-action role
correspondence, supported actor and target effect models, a computed horizon-one
successor, and positive predicted change in the active potential. The successor
settlement tests identity before attributing the mechanism.

Every executable proposal freezes the exact predecessor snapshots of its
controlling role bindings. Settlement reads those immutable snapshots, not the
observer's mutable `last_regions`. This matters because the live runtime may fit
the successor workspace before settling the preceding action. Without the
frozen basis, a valid observation can become `missing-predecessor` merely because
the frame-local binding IDs have advanced.

Unknown-mechanism probes are chosen from the retained comparative front in
`bounded_rank` order. Stable binding-ID order is only the final tie-breaker; it
cannot make a dominated or lower-ranked role tuple drive the first intervention.

The independent synthetic grounding tests translate scenes, swap values, scale
figures, replace their geometry with T, Z, and irregular congruent forms, and
add distractor fragments. An intentionally incorrect suggested clue cannot
erase the congruent structural pair; the same clue marked `required` is honored
as a hard constraint.

### Evidence-gated identity through mutual occlusion

R2.1 admits one limited alternative to connected-component identity when two
already tracked roles overlap. This is not a permissive merge heuristic. A
latent translated successor is fitted only if all of these constraints hold:

```text
both role transformations have supported action models
the two predicted occupancies overlap
every predicted cell outside that overlap visibly has its role's value
every ambiguous cell lies inside the other role's predicted occupancy
every ambiguous pixel has one of the two tracked values
at least one source-valued cell remains visible
```

When both roles pass, R2 installs two ordinary `region-binding` atoms with
ground support labeled `model-supported-mutual-occlusion`. The raw successor
components remain evidence atoms, but fragments explained by the joint
occupancy are removed from the next role-candidate cut. Thus the next decision
can continue to bind the tracked wholes rather than rebinding FIT to whichever
visible fragment happens to remain connected.

This factorization is defeasible. An unexplained value in an exposed predicted
cell rejects it; total disappearance, unsupported motion, out-of-frame motion,
merge with an untracked object, split, rotation, and deformation remain open.
The fitted latent occupancy is therefore a narrow causal hypothesis with an
observable checkpoint, not a claim of universal object permanence.

### Historical control failures and newer AR25 evidence

Earlier categorical and abductive implementations passed their runtime
contracts but did not clear AR25 level 1. One live episode exhausted all 48
actions with zero levels completed. This historical control failure remains
important evidence; it must not be erased by later successful runs.

An earlier decisive trace was:

```text
early FIT grounding:
    actor.area  = 45
    target.area = 45

late FIT grounding:
    actor.area  = 1
    target.area = 1
```

The verb and scalar potential remained formally admissible after their roles
had rebound to incidental one-pixel components. The controller then optimized
a decreasing `fit_residual` for the wrong situated objects. At the same time,
one observed action was attributed independently to several changed fragments,
polluting the region-type action model.

This establishes three limits of the implemented controller:

1. frame-local structural satisfaction is not persistent object identity;
2. more recursively available bindings increase ambiguity unless control has
   an explicit continuity and uniqueness gate;
3. greedy one-step residual descent is not milestone planning and can remain
   coherent while going nowhere.

The older PCW v1.16 AR25 result is the relevant empirical warning. It completed
level 1 in 38 actions only after proposal, exhaustive grounding, ambiguity
probes, semantic revision, unique grounding, and prospective confirmation.
R2.1 must preserve that epistemic gate while extending the representation.

A later 48-action run exposed a separate precursor failure: Qwen proposed the
correct verb `fit` but an incorrect hard role clue. R2 produced zero situated
goal groundings, zero prospective predictions, and zero changed control
decisions, so the fallback sequence repeated. Defeasible comparative grounding
repairs that representational veto: on the saved initial AR25 frame, the same
incorrect clue now retains four Pareto hypotheses, with the two orientations of
the congruent 45-cell pair ranked first. This is grounding evidence, not yet a
claim that the level is cleared.

A fresh live run after freezing predecessor evidence and ranking probes by the
comparative front produced a stronger control trace. R2 kept the two 45-cell L
shapes as `actor` and `target`, learned that action 2 translated the actor by
`(3,0)` while the target stayed fixed, and repeatedly confirmed the model as
the observed boundary gap decreased:

```text
28 -> 25 -> ... -> 10 -> 7 -> ... -> 3 -> 0
```

At turn 14 both identities were still `UNIQUE`, the predicted and observed
delta agreed, and `boundary_gap` reached zero. The next overlap then exposed
the connected-component limitation and produced `identity-broken`. The
evidence-gated mutual-occlusion factorization above was implemented and tested
after that trace. A subsequent fresh run again grounded the 45-cell pair and
confirmed early progress (`31 -> 28`), but was interrupted before overlap.
At that point, approach-to-contact behavior was live-proven while continuation
through overlap was only contract-tested; it was not yet a live game-clear
result. The later evidence below supersedes that game-clear status without
erasing the earlier failure boundary.

After the identity, settlement, game-scope memory, and bounded fast-path work,
a newer fresh run completed AR25 level 1 in 17 actions and advanced into level
2. The later breadth campaign isolated and repaired a stale command/effect-scope
attribution at the exact action-13 pivot. Three repaired long-budget traces then
reproduced the same action-17 clear. The primary 25-game pass and the final
six-game realistic-budget slice each contained one AR25 clear and no clear in
another game.

ARC resets the per-level action budget while R2 retains only explicitly
game-scoped knowledge:

```text
retained:
    empirical action-effect tables
    action-use statistics and semantic aliases
    schema confirmation/refutation counts
    recursive schema definitions
    durable game-level semantic note

re-grounded:
    regions and role bindings
    coordinates and current potentials
    role trajectories
    pending predictions
```

At the authoritative action-17 boundary, the first level-2 decision had unique
current correspondence but both role identities were UNINITIALIZED, its
mechanism was UNKNOWN, and predicted progress was null. It therefore remained
`PROBE_ELIGIBLE` rather than inheriting control authority. This demonstrates
safe re-grounding, not useful structural transfer. The stored fresh level-2
artifact has a different initial layout and cannot serve as a matched
carried-versus-fresh control.

## Prospective R2.1 control architecture

The following section describes the larger control commitment. Parts explicitly
marked implemented above—bounded alternatives, persistent translation
trajectories, frozen predecessor evidence, and mutual-occlusion factorization—
already exist. The remaining plurality, search, and identity regimes are
prospective.

### 1. Plural perceptual factorizations

R2 should derive several compatible object hypotheses from the same pixels:

```text
four-connected components
color regions
enclosed figures
outline-plus-interior composites
co-moving pixel sets
temporally conserved wholes
```

No one parse becomes empirical truth merely because it was produced first.
Each factorization is a schema binding with predictions, support,
contradictions, and scope. An action can provide evidence that disconnected or
internally marked pieces belong to one controlled whole when they transform
together.

### 2. Persistent causal role identity

Explanation roles must denote trajectories, not fresh frame-local regions.
For a role such as `actor`, R2 should fit a temporal correspondence:

```text
actor_t  <- correspondence_t ->  actor_t+1
```

Its residual vector should include at least:

```text
structural conservation
area/interior conservation
plausible spatial transformation
causal response to the observed action
continuity with the explanation's previous role binding
```

This is categorical object permanence: identity is the best-supported temporal
morphism, not a hidden permanent label and not equality of color or position.
A candidate whose area changes from 45 to 1 cannot inherit the actor role
without an explicit fragmentation/deformation explanation that predicts that
change.

Role continuity is a control-eligibility condition. When it fails, the current
explanation becomes structurally unresolved and cannot authorize a
goal-progress action.

### 3. Executable state-dependent dynamics

Observed action effects should compile into conditional transition clauses over
tracked wholes:

```text
ACTION_RIGHT(actor) -> Translate(actor, 0, +d)
    if PathOpen(actor, right)

ACTION_RIGHT(actor) -> Stable(actor)
    if Blocked(actor, right)
```

The learner must distinguish actor motion, other-object motion, animation, and
incidental changed fragments. A clause records its preconditions, support,
counterexamples, confidence, applicable identity trajectory, and provenance.

A prediction mismatch may indict any of:

```text
transition clause
action precondition
object identity
segmentation/factorization
latent state
goal explanation
```

Accommodation must therefore be able to return to perception and role binding,
not merely lower the confidence of the selected action.

### 4. Grounded milestones

A verb supplies a preferred transformation but not necessarily the next useful
checkpoint. The prospective controller should bind a small milestone graph over
the active explanation:

```text
goal hypothesis
  -> next discriminating or progress milestone
  -> object-level transformation or route
  -> one legal primitive action
  -> executable successor checkpoint
```

For example, a situated FIT explanation might yield:

```text
preserve actor and target identity
-> reduce horizontal displacement to zero
-> reduce vertical displacement while preserving reachability
-> achieve exact translated occupancy
-> verify terminal environment response
```

Milestones are grounded desired deltas with observable completion predicates,
not linguistic labels. A successful maneuver stores its preconditions, cost,
failure modes, and provenance and may later become a skill schema.

### 5. Internal model-predictive search

Once the relevant dynamics are supported, R2 should search freely inside the
learned model. Geometry, pathfinding, collision checks, and bounded BFS/A* are
internal computations and spend no environment actions.

For current state `S`, eligible action morphisms `a_i`, active explanation `E`,
and its preferred-completion potential `V_E`, control evaluates predicted
successors:

```text
a_i : S -> S_i

score(a_i) =
    expected milestone progress
  + expected hypothesis discrimination
  + option preservation
  - prediction uncertainty
  - identity risk
  - hard risk
  - redundant action cost
```

Only predictions grounded in the current persistent role bindings are
eligible. If no supported action model exists, R2 selects a one-step,
falsifiable probe that best separates live mechanic or identity hypotheses.

### 6. Exactly-one-action execution remains invariant

Internal search may produce a route or maneuver, but the environment interface
still commits exactly one primitive action:

```text
fit identities and explanations
-> choose the next milestone
-> search predicted successors internally
-> commit one legal action
-> observe the full successor frame stack
-> test identity, mechanism, milestone, and terminal predictions
-> preserve, revise, invalidate, or replan
```

A cached route is advice, not authority. It is cancelled immediately when an
identity correspondence breaks, a predicted delta fails, an unexpected event
appears, a goal/progress signal changes, or a precondition no longer holds.

### 7. Control eligibility gate

An explanation may control only when all of the following hold:

```text
roles are grounded to persistent trajectories
the verb's potential is measurable
the proposed action has a supported conditional effect
the predicted successor advances a milestone or discriminates live hypotheses
the prediction exposes an observable checkpoint
no fresher evidence contradicts the representation or mechanism
```

Otherwise the explanation remains useful epistemically but is not executable.
This restores the distinction between a plausible high-order fit and a winning
situated theory.

## Semantic model authority

The configured semantic model is a semantic proposer, not the executor. The
current Arcade exposes bounded default profiles for Qwen and GPT Luna, but the
authority contract is provider- and model-independent.

It may propose reusable verb names, abstract role ports, categorical role
constraints, a potential vocabulary item, a preferred order, a typed terminal
class, and open semantic questions.

Prospectively, the same authority boundary should permit Qwen to propose
alternative factorizations, identity correspondences, missing state variables,
and grounded milestone candidates. Those additions remain proposals: they gain
no control authority until R2 fits and tests them.

It may not choose an environment action, bind roles directly to visible object
IDs, claim empirical support, declare a proposal grounded or successful, or
override environment evidence.

R2 alone validates, binds, projects, selects one action, and settles evidence.
The environment alone supplies successor facts and empirical support.

### Current semantic-model process boundary

The current implementation uses one configured model profile per run and one
semantic inference response containing two strictly separated channels:

```text
model_scratchpad
workspace_write
```

`model_scratchpad` is the exact canonical five-string object shown above. It is
bounded, unverified, rewritten rather than accumulated, read by later semantic
turns, and displayed by Arcade without inventing a second UI-only semantic
state. The workspace write is structured, cited, and defeasible. R2 action
traces are appended to scratchpad context after every transition.

`workspace_write` also contains `abductive_compositions`. On a later turn the
configured semantic model must propose exactly one small candidate diagram when R2 exposes at least two
stable definitions. It may compose two or three of those IDs, connect them with
one to three typed morphisms, and project at most two residual orientations.
This is a serialization and attention bound, not an ontological limit: later
rounds can recursively compose the resulting definition. R2 resolves the
stable definitions to current situated bindings, rejects stale or ill-typed
references, and materializes accepted completions as
`abductive-composition-binding` atoms plus ordinary projected shadows.

The accepted workspace note is also the controller's latest semantic input.
The frame-zero explanation is only its predecessor; it cannot mask later verb
or abduction proposals. The controller reads `goal_proposals` and
`abductive_compositions` from that accepted note; it does not compile the five
scratchpad strings into control. Thus the live route is explicit:

```text
semantic-model workspace_write
  -> accepted bounded scratchpad note
  -> R2 verb and diagram grounding
  -> situated bindings and open shadows
  -> one-action ranking
```

After every ranking and settlement, R2 also publishes a bounded
`r2_semantic_projection`. It is a typed attention cut—not a dump—containing:

- the active and a few competing executable explanations;
- grounded verb roles and the current potential;
- preferred completion, causal mechanism, and expected progress;
- confirmations, refutations, and the latest environment settlement;
- salient structural bindings and unresolved shadows;
- a compact recursive-schema summary.

The next semantic-model turn reads this projection and may preserve, revise,
or replace its abstract verb proposals. Authority does not flow backward: the
model's revision remains a proposal and must pass through R2 grounding again
before it can influence action selection. Both the projection and action
traces are cleared at episode boundaries.

Visual evidence is an explicit causal unit. Frame zero contains only
`CAUSAL_UNIT_CURRENT_FRAME` with `predecessor=none`. Every later semantic turn
begins with the exact `CAUSAL_UNIT_PREVIOUS_FRAME`, followed by the exact
`CAUSAL_UNIT_CURRENT_FRAME` for the same transition. A structured
`r2_transition_observation` binds that pair to the historical action, R2's
observed delta, and the prediction settlement. At most one older structurally
salient frame may follow, clearly marked as context rather than the current
successor. The semantic model may interpret this history but still cannot
choose the next action.

This is currently one inference call with two output channels, not two
independently scheduled semantic calls. The representation and write
authorities are separated even though the configured model process is shared.

The current production loop makes every settled observation require semantic
revision before the next external action. The model therefore receives the
latest causal visual unit, R2 settlement, semantic projection, and exact prior
scratchpad together. A response is accepted only against the evidence basis it
read; a stale response cannot replace the current workspace state. Frame zero
is likewise synchronous because the first action requires a durable explanation
by contract. Deep explanation consolidation is a stronger boundary gate: the
first successor-context action waits for a valid reusable proposal or explicit
abstention.

Refresh scheduling is demand-driven rather than periodic. A request is queued
only for initial semantics, newly observed transition evidence lacking an
action alias, an exact eligible causal-revision packet, or a canonical semantic
failure signal. Pending-work and evidence-key gates prevent polling and exact
duplicate work. Positive action-count cadence does not itself request the
semantic model.

Request construction enforces the active profile's context and output reserve
against the serialized request. The local Qwen defaults remain a 16,384-token
context and 2,048-token ordinary output reserve. GPT Luna uses its server-owned
profile defaults, including a 1,050,000-token context, 8,192-token ordinary
output, 16,384-token consolidation output, a 12,000-token R2 frontier, medium
ordinary reasoning, and high consolidation reasoning. Because
sparse-frontier size is a staircase rather than a continuous function of its
nominal budget, retries cross the actual rendered-cut breakpoint. If bounded
rebuilding reaches mandatory closure, one exact-admitted richer probe may be
accepted only when it retains more objects; otherwise the already admitted
mandatory request is returned unchanged. In a frozen audit this recovered
nonempty attention in 34/35 formerly empty turns without weakening evidence or
reserve invariants.

Historical opaque-action language in the semantic scratchpad is evidence, not
an executable proposal. The compiler permits an action mention only when it is
causally adjacent to a bounded observed-outcome phrase and contains no modal,
future, directive, or competing-action language. Action aliases remain a
separate evidence-cited field. This recovered the stored retrospective failure
corpus while preserving fail-closed rejection of recommendations.

Budgets are resolved and frozen per run rather than shared across unlike
models. Unknown OpenAI model limits are never guessed: a custom profile must
supply every required budget dimension. Invalid JSON or a response that fails
the strict provider-compatible schema is rejected without granting semantic or
control authority. On a later semantic refresh the correct Arcade message is
`semantic update rejected; grounded control continues`; only a rejected
required frame-zero explanation prevents the first action.

## Arcade contract

The arcade exposes the epistemic system rather than only the pixels. Its full
right-hand panel renders the current durable `workspace_write` as readable
fields and typed cards rather than one undifferentiated JSON dump. It includes:

```text
summary and objective hypothesis
typed goal/verb proposals
abductive compositions and morphisms
open questions and action aliases
the exact five-field model scratchpad
cited evidence and workspace metadata
```

Raw JSON remains available inside each field for audit. Separate R2 panels show
the current executable explanation, ranked actions, salient verb lifecycle,
recursive schema levels, categorical diagrams, and settlement feedback. Model
prose remains visibly marked unverified and is never presented as the
executable explanation.

The game canvas shows action budget, actions remaining, level progress, and
agent state. Runs retain versioned metadata and replay timelines. Action
aliases are rendered consistently with per-action colors wherever they appear.
A colored detailed log at the bottom records actions, decisions, settlements,
schema fitting, Qwen phases and rejections, level transitions, alias changes,
and fast-path authorization or revocation. This log is presentation telemetry,
not evidence available to the controller.

Every ordinary intervention has one durable identity chain:

```text
ActionDecision(selected_command)
→ ActionPending(action_id, data, command_id, effect_scope_id)
→ environment execution
→ TransitionCommitted(action_id, data, before, ordered successor envelope)
→ next-turn settlement(command_id, effect_scope_id)
```

For coordinate actions, `data={x,y}` must come from a current-frame observed
region cell and retain its frame digest and region binding. No coordinate is
fabricated or recovered from stale advice. A multi-frame environment response
retains all support frames in order; only the designated settled frame becomes
the controller's next state.

## Piagetian interpretation

```text
Assimilate
    Fit structural and verb schemas to the present workspace.

Anticipate
    Project causal successors and preferred-completion shadows.

Act
    Choose one causal morphism predicted to advance the active verb.

Compare
    Test the projected successor against environment evidence.

Accommodate
    Reject, revise, or restructure verbs and explanations that fail.

Equilibrate
    Retain and eventually promote structures that survive across contexts.
```

A verb is a Piagetian action schema stripped of specific motor commands: it
organizes preferred completion, while learned causal schemas provide the
currently available means.

## Anti-overfitting commitments

R2.1 deliberately avoids:

- game identifiers inside schemas;
- fixed object roles tied to colors or coordinates;
- hardcoded action meanings;
- a privileged geometric goal injected by R2;
- treating Qwen prose as evidence;
- treating a proposed verb as grounded;
- executing a multi-action chain without observing intermediate frames;
- imposing a fixed recursive depth as an ontology.
- embedding an AR25-specific route, color-role assignment, or action map in
  the prospective controller;
- treating successful schema fitting, high binding counts, or error-free
  execution as a substitute for environment progress.

The reusable primitives are categorical relations, measurable potentials,
partial orders over completions, causal transformations, and recursive schema
composition. Specific goals emerge only when those generic structures bind a
particular frame.

## Episode isolation and arcade reliability

Level transitions and episode resets have different scopes. Within one ARC
game, completing a level preserves supported game-level knowledge: empirical
action effects and usage, explanation support/refutation, the recursive schema
graph, and the durable semantic working note. The first frame of the next level
is then re-grounded from scratch. Frame digests, coordinates, region/role
bindings, trajectories, current potentials, pending predictions, and
same-frame no-change exclusions do not cross that boundary.

ARC's engine calls `set_level()` while advancing and resets its internal action
counter there. R2.1 mirrors that contract: the configured action budget is a
per-level cap, while the run history and score remain cumulative across the
game. The winning action is recorded as level-completion evidence, but the
replacement board returned with it is not learned as an object-level causal
transformation from the completed board. The agent proceeds until ARC reports
a terminal state or the current level exhausts its own action budget.

Current empirical action effects are indexed by the exact region type:

```text
(action ID, palette value, area, normalized shape)
```

This prevents unsupported transfer but is stricter than the intended reusable
schema semantics. Two visually similar levels can therefore retain an effect
table yet fail to apply it to a structurally corresponding role whose exact
type key changed. A prospective generic remedy is hierarchical applicability:

```text
exact grounded type
    -> structural type modulo palette value
    -> broader game-level action semantics, only when evidence is consistent
```

Every backed-off prediction would still execute once and require immediate
settlement. This hierarchy is not implemented and must not be confused with
the implemented fast path, which can only use causal effects already judged
applicable to the current state.

Every arcade start is a new epistemic episode, even when its first frame is
pixel-for-pixel identical to the preceding run. Before environment execution,
the runtime calls `FrameSchemaObserver.reset_episode()`. This clears:

- the frame-digest cache and recursive workspace;
- bindings, atoms, shadows, and prospective potential states;
- learned action effects and action-use counts;
- pending predictions and confirmation/refutation counts;
- verb, action, and rejected-proposal registries.

Caching an unchanged frame remains valid *within* one episode. Reusing a cached
workspace *across* episodes is forbidden: it would turn evidence learned in one
game into an unexplained prior in the next.

The durable Qwen turn keeps its full materialization and object index for audit
and response validation. The inference transport sends the bounded sparse cut
and explicitly omits those two redundant structures. This matters on visually
busy games: bounding the sparse cut is insufficient if the same request also
serializes the entire graph. The canonical turn remains untouched, so transport
compaction changes neither citation authority nor compilation semantics.

Schema fitting is also idempotent. A request for an open preferred-completion
binding may find either a partial binding or an already reified binding. Both
are valid states. The latter is reused as satisfied structure; it must never
raise merely because no partial candidate remains.

The executable contract is covered by tests for fresh frame-zero workspaces,
three consecutive identical episodes, reset delegation, repeated ranking after
completion, causal learning and settlement, UI surfaces, frame serialization,
Qwen contracts, and the recursive schema engine. The operational smoke test is
to start multiple arcade runs in succession and require each to pass frame-zero
explanation, action selection, and settlement without entering `error`.

## Current limitations

The implemented representational architecture remains provisional as a game
controller:

- broad score remains weak: the primary 25-game pass cleared only AR25 level 1
  despite 383 committed actions;
- click execution is grounded, but click causality is not: most settled clicks
  were unchanged, ambiguous, or associated only with distant global-carrier
  footprints, and none earned supported causal authority;
- accumulated mechanism evidence rarely becomes milestone or route control;
  most primary decisions remained information probes rather than predicted
  goal progress;
- `model_scratchpad.game_objective` and the prose `objective_hypothesis` are
  visible to the semantic model but are not compiled into the action ranker;
  structured goal proposals can therefore optimize a locally coherent residual
  without a represented causal link to level completion;
- R2 has an internal active explanation, pending prediction, and bounded fast
  path, but no first-class shared explanation-lock object; the semantic
  scratchpad may drift toward a reusable abstraction while situated control is
  committed to a more specific binding;
- explanation consolidation optimizes evidence-preserving reuse and fresh
  falsifiability, but there is not yet a game-level selection criterion that
  promotes an abstraction specifically because its verb completion caused a
  level completion;
- semantic proposal quality remains model-dependent; changing from local Qwen
  to GPT Luna changes proposal quality and latency but grants no additional
  grounding or control authority;
- only a small potential vocabulary currently has measurement adapters;
- action effects are simple empirical translations indexed by exact command
  scope and region type;
- exact `(value, area, shape)` effect indexing can make cross-level reuse too
  conservative, while evidence from several situated roles can make one exact
  type contested; hierarchical invariant-aware backoff is not implemented;
- role-hypothesis IDs and bounded correspondences preserve translation, reject
  gross area collapse, and support a strictly gated two-role mutual-occlusion
  factorization, but do not yet solve arbitrary merge, split, total occlusion,
  rotation, or deformation identity;
- connected components remain the default parse; the installed occlusion
  factorization prevents explained fragments from replacing tracked wholes,
  but interior marks and unrelated fragments can still create ambiguity;
- greedy one-step potential descent has no milestone graph, route search, or
  certified executable simulator;
- `grounded-open-mechanism` probe records are still labeled explanations when
  their quantitative prediction is null; until they expose bounded diagnostic
  successor shadows they are descriptive or proto-explanatory bindings under
  the stronger generative invariant;
- supported mechanisms currently publish one selected quantitative prediction,
  not a bounded ordinary-shadow frontier containing the relevant competing
  completions;
- consolidation now projects a fresh-binding goal diagram live, but the
  expected re-grounding itself is not yet represented and settled as a first-
  class cross-context shadow;
- prediction failure does not yet reopen segmentation and state factoring as
  first-class competing hypotheses;
- correspondence through disappearance, untracked merging, rotation, and
  deformation is still weak;
- categorical residuals currently use a small generic projection vocabulary;
  learned quotient/invariance discovery and causally justified regime
  promotion are not complete;
- Qwen abductive compositions are grounded as structural diagrams with open
  prediction shadows, but recurring successful compositions are not yet
  promoted automatically through a universal abstraction;
- accommodation rejects incoherent proposals but does not yet autonomously
  invent a repaired telic schema;
- explanation consolidation now persists zero-authority reusable schemas and
  freshly re-grounds them, but recurring abstractions are not yet promoted to
  durable skills; the bounded fast path remains temporary situated execution
  authority, not skill promotion;
- accepted semantic proposal sets often repeat without producing a new telic
  or milestone hypothesis; prediction refutation alone must not force churn
  when the grounded verb and mechanism remain supported;
- the scratchpad and semantic workspace channels share one model inference call;
- semantic-model structured responses can still be malformed or reach their output
  ceiling; ordinary post-frame-zero responses are rejected safely while
  control continues, whereas an invalid boundary consolidation blocks the
  first successor-context action until a later valid proposal or abstention.

These are extension points inside the same schema language, not reasons to add
a separate planner ontology.

## Short form

> A verb is a generative schema over preferred transformations. A goal is the
> terminal completion of a situated verb. An explanation is a recursively
> grounded graph that joins structural schemas, a verb, a potential, causal
> effects, and at least one non-vacuous projected shadow beyond present
> support. A binding without that empirical risk is descriptive or
> proto-explanatory. Implemented R2.1 executes
> exactly one action supplied by a learned causal binding, observes the result,
> and settles it. After repeated confirmed preferred transitions, R2.1 may
> temporarily reuse the grounded state-conditioned policy for a bounded number
> of actions, still predicting, observing, and settling each action and
> revoking authority on the first mismatch. Across levels of one game it
> retains supported schemas and mechanics but re-grounds the instance.
> Prospective R2.1 adds stronger persistent causal identity, plural
> factorizations, hierarchical cross-level applicability, grounded milestones,
> and internal model-predictive search while preserving the
> exactly-one-external-action invariant. The current breadth-tested substrate
> represents that intervention as one exact grounded `ActionCommand`, preserves
> the ordered successor evidence, and settles command-scoped predictions before
> replanning. Its exact five-field model scratchpad is fluid shared semantic
> state, not control authority: structured verb proposals and abductive
> compositions drive R2 grounding, while the scratchpad `game_objective` does
> not yet constrain ranking. Thus the implemented loop connects explanations
> and verbs strongly to local predicted progress, but a prospective goal
> contract and first-class explanation lock are still required to connect that
> progress explicitly to beating the game. The current system has repaired one
> replicated AR25 scoring boundary, but broad score remains limited by situated
> causal attribution and plan quality.
