# Parallel Cognitive Workspace v1.14

v1.14 is a separately frozen successor to the valid but control-negative v1.13
ar25 pair. It inherits the fresh paired arms, 64-action budget, live-Qwen call
schedule, context limits, typed four-plus-one probe budget, replay checks,
support-authority rules, and PASS/FAIL/INVALID criteria unchanged.

The v1.13 causal loop reached live proposal, three R2 groundings, four active
probes, eight environment-supported predictions, and evidence return to Qwen.
It failed because the repair context exposed only a partial ambiguity witness:
Qwen repeatedly chose a temporal predicate that did not uniquely ground.

v1.14 freezes three generic interface repairs:

1. From the complete action-free grounding state, R2 renders the exact unordered
   effect-pair extension of every allowed predicate and labels it empty, unique,
   or ambiguous. Missing facts become false only when the entity and relation
   populations are explicitly complete and non-truncated.
2. Exact probe outcomes and action-free temporal relations annotate effect pairs
   with relative-motion control leverage. This is attention guidance, never
   empirical support for a schema.
3. A rejected semantic revision becomes a durable Qwen-attempt object plus a
   separate kernel compiler-criticism object. The criticism receives attention
   on the next Qwen turn but creates no support/refute/invalidate edge.

The frame/HUD remains present in the visual world and graph. The diagnostic may
surface replacement pairs outside an earlier bad candidate set; it does not hide
objects, inject a schema, name a game role, expose an action meaning, or grant
epistemic authority. No previous response, schema, workspace, notes, solution
trace, or action ledger may seed either fresh arm.
