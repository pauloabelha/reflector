# Parallel Cognitive Workspace v1.7

v1.7 is the separately versioned replacement for v1.6's exact-closure
infeasibility. All scientific settings remain unchanged.

The sole new change normalizes each prospective binding to its exact situated
facts: schema/template reference, candidate ID, effect pair, population counts,
revision eligibility, and legal-action cardinality. The complete ambiguity
witness remains exact once in the dependency-linked structured criticism. It
is no longer copied wholesale into every candidate binding. This is lossless
normalization of shared facts, not epistemic deletion or a larger token budget.
