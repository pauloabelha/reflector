# Grounded symbolic progress development gate v1

`tr87` is now consumed development data.  R2 must derive all token identities,
example pairs, query slots and editable slots from pixels and calibrated local
effects.  Qwen receives only opaque token IDs and the current frame, writes one
support-zero transformation proposal, and cannot emit actions.  R2 validates
the proposed tokens against demonstrations and performs closed-loop cyclic
edits with the calibrated opaque mutation/selection interventions.

PASS requires live Qwen to emit the exact demonstrated output sequence, level
1 completion within 24 total actions, and exact replay.  No source identifier,
symbol name, fixed answer, coordinate, color, or action sequence is allowed in
the implementation or prompt.
