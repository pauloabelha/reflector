# Frozen expanded progress-ontology cross-test

Before opening a target frame, select one non-consumed `keyboard_click` game by
the committed metadata-only hash rule. Run two fresh arms from matching initial
digests: a 48-action simple cycle and the frozen shared progress ontology.

The treatment first runs the unchanged translation, conditional-route, and
symbolic-substitution dispatcher from v1. If those mechanisms abstain and a
parameterized action exists, it may construct support-zero grounded interaction
addresses from connected components in a visually separated pane. Qwen may
write only the generic objective `IncreaseReachableSet` / `ReachTerminal`.
R2 searches exact observed successor states using opaque simple and grounded
parameterized interventions. No source, game ID, route, coordinates, action
meanings, prior target artifact, or dc22 semantic output enters the workspace.

Primary pass: shared completes level 1 within 48 factual actions while baseline
does not, or saves at least 25%, with matching start and exact factual replay.
Planning reset/intervention count is reported separately and is not hidden.
