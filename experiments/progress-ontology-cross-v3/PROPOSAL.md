# Frozen progress ontology v3 cross-test

The metadata-only selector is frozen before target construction. Two fresh arms
receive 48 factual actions. The shared arm uses the unchanged v2 dispatcher plus
the new generic multi-object placement family: filled movable equivalence class,
hollow compatible slots, obstacle bands, `BlockedAssignmentCount`, aligned
prospective pushing, template-preserving correspondence after contact, and
dynamic re-grounding of parameterized selections. Four reset calibration probes
are allowed and reported separately. Qwen writes only a support-zero progress
goal; it cannot emit actions, coordinates, colors, a route, or game knowledge.

Pass requires matching starts, exact replay, and shared L1 when cycle does not,
or at least 25% fewer factual actions if both solve. A typed ontology abstention
is a valid negative result, not infrastructure invalidity.
