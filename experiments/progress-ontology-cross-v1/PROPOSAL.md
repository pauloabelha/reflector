# Frozen progress-ontology cross-game gate v1

Metadata-only selection fixes `dc22-fdcac232` before frame inspection.  Two
fresh arms share the same initial state and action budget.  `r2_cycle` performs
the generic simple-action calibration then cycles opaque actions.
`shared_progress_ontology` dispatches, without target-specific fallback, among
three previously earned classes: complete cardinal translation, sparse
state-conditional route motion, and localized symbolic substitution.

Qwen sees the current frame and the selected grounded effect workspace.  It
writes support-zero semantics only; R2 grounds and executes.  PASS requires the
shared arm to complete level 1 within 32 actions with exact replay while the
cycle arm does not, or to save at least 25 percent if both complete.  A missing
effect class is a valid FAIL and consumes the target for development.
