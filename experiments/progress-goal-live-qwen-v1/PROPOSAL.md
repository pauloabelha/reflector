# Live semantic reconstruction of a progress goal v1

This is a development-game gate following the support-zero intervention result.
It asks whether a live Qwen worker can construct the same *kind* of executable
progress object without receiving that object, a situated binding, or an action
sequence.

One fresh `wa30` episode begins with an empty epistemic workspace. R2 executes
the frozen common calibration prefix: every available simple opaque
intervention once in sorted order. It publishes the current frame, grounded
components, equivalence classes, capacity relations, and the observed
intervention-to-motion deltas. Qwen receives that world-facing projection and
may write at most one support-zero goal hypothesis.

The prompt exposes a broad, fixed family vocabulary: matching, alignment,
collection/containment, connectivity, avoidance, and transformation. It says
that a goal must include a terminal predicate and a measurable potential, but
does not identify which family or entities are correct. Output entity and
intervention references must come from the live workspace.

R2 validates and grounds the hypothesis. Only a complete collection hypothesis
has an executable planner in this version; other valid families remain durable
workspace objects and cause control abstention. No Qwen support value is
accepted. Environment transitions alone adjudicate progress.

PASS requires a valid live Qwen collection hypothesis, exact grounding without
oracle addresses, and level 1 completion within 40 total actions. A valid
noncollection proposal or no completion is FAIL. Transport/context/leakage,
support-authority, or replay failure is INVALID. This result remains wa30
development evidence; unchanged cross-game testing is required afterward.
