# Parallel Cognitive Workspace v1.6

This is a separately versioned replacement for the v1.5 `INVALID` gate.

All v1.5 scientific settings remain frozen. The only new correction preserves
the controller's executable grounding status when an ambiguity witness is
attached. The witness remains exact and its externally visible criticism is
still `ambiguous-grounding`; it may no longer overwrite the internal
`ambiguous-active` state that says the alternatives are live and probeable.

No prior response, schema, prediction, transition, or environment state is an
input. Both arms start from new empty workspaces. v1.5 evidence is used only as
a regression fixture proving the generic state-merge defect.
