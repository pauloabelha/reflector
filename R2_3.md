# Reflector II 2.3: unified semantic–epistemic control architecture

This document describes the architecture currently implemented on the R2 glue
branch after the semantic-schema and affordance-projection work. It is an
architectural specification, not a score claim. The executable still identifies
itself as R2.2 until the new boundary has enough cross-game evidence to justify
promotion. The optional `ProspectPlanner` remains an interchangeable planning
backend; it is not the definition of R2.3 by itself.

## 1. The central design

R2 is one settlement-synchronous epistemic loop:

```text
world observation
    → R2 extracts typed, non-semantic structure
    → Qwen uses broad learned priors to propose meanings and goals
    → R2 compiles those proposals into measurable situated hypotheses
    → R2 grounds entities and predicts exact command consequences
    → R2 authorizes exactly one external action
    → the environment supplies the successor and terminal facts
    → R2 independently settles identity, mechanism, goal, schema, and terminal
    → the settled projection returns to Qwen for revision
```

Qwen is the broad prior machine. R2 is the epistemic and control machine. The
environment is the only source of empirical settlement.

The architecture is deliberately neither an LLM policy nor a closed symbolic
solver. Qwen can introduce a previously unnamed concept such as alignment,
complementarity, insertion, obstruction, collection, or avoidance. R2 does not
need a complete hand-written ontology for those meanings, but it does require a
bounded measurement, typed roles, falsifiable predictions, and environmental
evidence before the concept can control anything.

## 2. Non-negotiable invariants

1. **One semantic state.** Qwen has one five-field prose scratchpad and one
   structured write. The structured write does not duplicate free-text summary
   or objective prose; R2 derives those from the scratchpad. A goal has one
   typed terminal relation/target; R2 attaches the selected observable and
   direction and derives canonical terminal text.
2. **One semantic projection.** Perceptual opportunities, grounded schemas,
   causal entities, prediction settlements, and compiler feedback all enter
   Qwen through `r2_semantic_projection`. There is no second affordance memory
   or parallel Qwen channel.
3. **Proposal is not evidence.** Model confidence is an attention prior only.
   Every model-originated goal, schema, analogy, composition, and measurement
   starts with zero empirical support.
4. **Semantics never directly select an action.** Qwen cannot emit a direction,
   button, route, situated object binding, or action policy. It proposes
   action-free structure; R2 projects that structure onto legal commands.
5. **One real action per cycle.** A planner may simulate several steps, but only
   its first exact command can be authorized. Every real successor invalidates
   the unexecuted continuation.
6. **Evidence axes stay separate.** Entity identity, action mechanism, goal
   progress, explanatory-schema fit, causal-entity membership, and environment
   completion cannot substitute for one another.
7. **Failure is explicit.** Empty features, ambiguous identities, unsupported
   effects, global-motion confounds, malformed proposals, and stale responses
   remain OPEN or are rejected; they do not silently become success.
8. **No target-game rules.** Production code contains no game identifier,
   palette mapping, fixed route, named shape solution, opaque-action meaning, or
   rule such as “holes imply fitting.”

## 4. Layer contracts and authority

| Layer | Receives | Produces | Authority |
|---|---|---|---|
| Environment adapter | ARC observation and legal action interface | exact current frame, causal frame pair, legal commands, outcome/terminal | authoritative for observations and terminals |
| Recursive frame observer | exact frame | primitive bindings, relational bindings, comparisons, open shadows | observed/derived geometry only |
| Affordance providers | currently fitted entities and channel-specific observables | anonymous measurable opportunities | attention only; no semantic or control authority |
| CAE | settled predecessor/successor and transformations | defeasible composite entities | support only from transitions; not a goal |
| Semantic projection | bounded cuts from R2 layers | one read-only model context | preserves the authority of each source field |
| Qwen | visual causal unit, prior scratchpad, semantic projection | prose state and structured hypotheses | proposal only |
| Semantic compiler | model response and exact turn basis | canonical goals, schemas, measurements, citations | validates; supplies no empirical support |
| Role grounder | compiled proposals and fitted entities | bounded Pareto role hypotheses | defeasible grounding only |
| Effect learner | exact commands and settled transitions | command-scoped effect distributions | empirical mechanism evidence |
| Controller | situated goals, effects, identities, invariants | eligibility and one selected exact command | sole action authority |
| Planner | immutable grounded control problem | prospective route and certificate | hypothetical until first-command gate |
| Settler | selected explanation and real successor | independent support/refutation counters | environment-backed adjudication |

The authority flow is monotone:

```text
semantic prior
  < compiled measurable hypothesis
  < situated open binding
  < environment-supported identity/effect/progress
  < environment terminal
```

No upper layer may manufacture a lower layer's evidence.

## 5. Observation and recursive fitting

### 5.1 Primitive bindings

The current visual adapter identifies modal background and fits 4-connected
same-value foreground regions. Each region becomes a `region-binding` with a
neutral spatial interface: occupied cells, boundary, envelope, centroid, area,
intrinsic shape, and topology.

Palette value and absolute location remain available to observation code but
are nuisance dimensions for semantic generalization. A semantic proposal may
use stable relational evidence such as same/different outline or interior, but
cannot bind a role directly to a color, coordinate, or visible object ID.

### 5.2 Recursive schemas

The frame observer fits promoted binary relations such as sameness,
difference, alignment, contact, and disjointness. It recursively composes
relation bindings, records partial bindings, and retains missing-port shadows.
Categorical comparisons create bounded correspondences among structurally
similar atoms without treating visual similarity as identity.

The recursive workspace is shared by ordinary visual relations, semantic
schema projections, causal composites, potentials, actions, comparisons, and
abductive compositions. They are typed objects in one epistemic substrate, not
separate ad hoc reasoning engines.

## 6. The pre-semantic affordance frontier

### 6.1 Why it exists

Raw images let Qwen recognize concepts, but R2 previously returned mainly the
measurement selected by an already existing goal. That made familiar measures
easy to verbalize and structurally important alternatives implicit. The model
could say “align” while never being shown that occupancy-to-negative-space,
containment, contact, or another relation was directly measurable by R2.

The affordance frontier exposes current measurement opportunities before Qwen
chooses their meaning. It answers:

```text
What relations can R2 measure in this observation?
```

It does not answer:

```text
What do those relations mean?
Which one is desirable?
Which pair is the actor and target?
Which action should be taken?
```

### 6.2 Provider contract

An affordance provider consumes bounded observations from one modality and
emits typed, anonymous summaries. The current provider implements spatial-set
relations. Future providers can use the same interface for temporal events,
inventory changes, textual instructions, scores, UI widgets, resources,
occlusion, or interaction graphs.

The frontier therefore is not a spatial ontology. Spatial sets are the first
provider because the current ARC environment is a grid.

```text
AffordanceProvider.observe(observations)
    → observation_family
    → provider_protocol
    → typed measurement template or channel-specific test
    → measurability counts
    → normalized alternatives and scale bands
    → semantic_label = null
    → desired = null
```

### 6.3 Current spatial probes

The current provider compares bounded combinations of:

- occupancy;
- boundary;
- enclosed negative space;
- empty space inside an entity's rectangular envelope.

It uses declared set comparisons in either scene coordinates or intrinsic
coordinates. Scene measures can include separation to preserve a control
gradient before contact. Intrinsic measures expose structural compatibility
without claiming that current location is already a terminal.

These are measurement primitives, not verbs. Occupancy-to-negative-space may
support many semantic interpretations, or none. Qwen decides whether an idea
such as complementarity, fitting, insertion, obstruction, or enclosure is a
plausible explanation. R2 later tests the interpretation.

### 6.4 Anonymous aggregation and scale

The frontier does not expose current binding IDs. It reports candidate counts,
unmeasurable counts, best and runner-up normalized residuals, distinctiveness,
near-best multiplicity, feature support, and logarithmic support-scale bands.

Candidate counting respects the measurement algebra. Same-feature commutative
relations quotient the reversed entity pair, so a unique pair is not reported
as its own tied runner-up. Asymmetric comparisons and differently typed
features retain ordered actor/target hypotheses.

Scale bands retain small, medium, and large opportunities simultaneously. A
pair of identical singleton markers must not erase a larger structural match,
and a large object must not erase a small but unique interaction affordance.
The frontier reports both; it does not choose which matters.

### 6.5 Provenance-bound opportunity references

Every reusable frontier measurement has an `opportunity_ref` and an exact
`measurement_template`. When Qwen bases a proposal on that opportunity, it
copies the template including `basis_opportunity_ref`. The compiler verifies
that it denotes the observation Qwen cites. Exact documents are canonical;
the only accepted alternative syntax is swapping the two operands of a
declared commutative comparison (`symmetric_difference_size` or
`overlap_deficit`), which the compiler rewrites to the canonical template.
Operand swaps remain meaningful and invalid for asymmetric unmatched-size
comparisons.

This closes a subtle semantic-binding failure:

```text
observed opportunity: occupancy → enclosed_negative_space
loose model transcription: enclosed_negative_space → enclosed_negative_space
```

Without provenance both are syntactically valid but mean different things.
With provenance, a cited function cannot be silently mutated. Qwen can still
invent a different bounded measurement, but it must set
`basis_opportunity_ref=null`, making the new construction explicit and OPEN.

## 7. The unified Qwen semantic bridge

### 7.1 One model-facing semantic state

The informal semantic state has exactly five fields:

```text
game_objective  current hypothesis about the environment terminal
explanation     smallest current account of what is happening
goal            current action-free subgoal
expectation     falsifiable next observation
notes           what changed, failed, or remains open
```

This exact object is stored in the ledger, rendered in Agent Arcade, supplied
to ordinary semantic turns, and supplied to level-boundary consolidation.

The structured `workspace_write` does not regenerate `summary` or
`objective_hypothesis`. R2 derives:

```text
stored summary             := scratchpad.explanation
stored objective claim     := scratchpad.game_objective
```

That prevents two independent pieces of model prose from representing the same
belief and drifting apart.

### 7.2 Structured semantic products

Qwen emits three distinct hypothesis types.

#### Goal proposal

A `goal_proposal` says what measurable relation may be worth changing or
maintaining. It supplies:

- a freely chosen canonical verb;
- a schema name and broad goal family;
- exactly two abstract control ports, `actor` and `target`;
- defeasible categorical role clues;
- a built-in or model-proposed measurement;
- preferred residual order and local terminal;
- optionally, an OPEN claim that the local terminal contributes to an
  environment terminal.

The verb has no fixed measurement mapping. `align`, for example, is not
hardwired to centroid distance or boundary gap. The declared measurement—not
the word—defines the potential R2 evaluates.

Qwen generates only the numeric/null target inside `local_terminal`. R2 derives
the terminal relation from `terminal_class`, injects the proposal's observable
and direction, then derives `terminal_condition`. Thus target, relation,
observable, direction, and rendered terminal text each have one source and
cannot disagree in separate model fields.

#### Semantic schema hypothesis

A `schema_hypothesis` says what relation or dynamic might explain the goal. It
links to one goal proposal and provides:

- `relational`, `dynamic`, or `relational_dynamic` kind;
- a model-named canonical `relation_family`;
- a claim over actor and target;
- predicted structural dynamics from a closed test vocabulary;
- explicit counterconditions;
- calibrated confidence and its basis.

The structured claim may mention only abstract ports such as `actor` and
`target`; situated frame aliases such as `f01` are rejected. Qwen can discuss
visible candidates in its unverified prose, but only R2 may bind a reusable
schema port to an entity.

`relation_family` is intentionally open to Qwen's broad prior. R2 no longer
forces every idea into a small enum such as alignment/contact/containment.
Qwen may coin `spatial_complementarity` or another canonical family. The
prediction and countercondition vocabularies remain closed because those are
the executable tests that keep a novel label falsifiable.

#### Abductive composition

An `abductive_composition` combines already situated stable schema IDs with
typed morphisms and predicted residual orientations. It lets Qwen propose a
larger explanatory diagram without copying or redefining its components.

### 7.3 Qwen's proper role

Qwen contributes what a large pretrained model is good at:

- recognizing analogies and familiar interaction patterns;
- proposing names that compress several observations;
- imagining hidden goals and object functions;
- relating topology, geometry, causality, and task conventions;
- generating competing explanations and counterconditions;
- revising the explanation when evidence conflicts.

It does not contribute:

- empirical support;
- current entity identity;
- opaque action meaning without transition evidence;
- a directly executable policy;
- success or completion judgments;
- permission to ignore an unmeasurable proposal.

## 8. Semantic compilation

The compiler is the boundary between linguistic freedom and executable
epistemology.

It enforces:

- strict JSON products and bounded array sizes;
- canonical symbols and typed ports;
- action-language quarantine outside retrospective cited aliases;
- consistent direction and local terminal;
- compiler-derived canonical terminal text;
- built-in versus proposed measurement separation;
- allowlisted declarative measurement operations;
- exact opportunity-template provenance when cited;
- current transition-basis and request-basis freshness;
- citation visibility;
- duplicate suppression;
- retirement of explicitly failed repeated goals;
- zero empirical support for model proposals.

Malformed siblings are quarantined independently. A useful scratchpad update or
valid goal does not have to disappear because a second proposal is malformed.
However, a nonempty model goal array whose every proposal fails compilation is
not reinterpreted as semantic abstention. That write fails atomically: the
prior shared hypothesis remains canonical, and a bounded
`semantic_compiler_feedback` diagnostic is attached to the existing R2
projection. The next Qwen turn either copies a cited affordance template
exactly or declares a genuinely new measurement with null provenance. This
keeps serialization failure from silently erasing control intent.

Model confidence is compiled to `attention_priority` only. It may break a tie
between otherwise comparable OPEN candidates; it cannot cross a control gate.

## 9. Measurement language

The current model-defined spatial measurement protocol is a small declarative
language:

```text
protocol: r2-spatial-set-residual-v0
left_source: actor | target
left_feature: occupancy | boundary | enclosed_negative_space |
              envelope_negative_space
right_source: actor | target
right_feature: same feature vocabulary
comparison: symmetric_difference_size | left_unmatched_size |
            right_unmatched_size | overlap_deficit
coordinate_frame: scene | intrinsic
include_separation_gap: boolean
basis_opportunity_ref: current frontier ref | null
```

An empty selected feature returns `None`, never zero. Intrinsic measurements
cannot include scene separation. Feature cardinality is bounded. No code,
arbitrary predicate, game identifier, color name, or action token can enter the
measurement evaluator.

This language is intentionally small. Qwen supplies semantic breadth by
composing primitives and predicting dynamics, not by injecting executable code.
Additional modalities should add equally explicit provider/evaluator contracts
rather than enlarge the prompt into an informal programming language.

## 10. Grounding roles and entities

### 10.1 Defeasible role grounding

R2 enumerates bounded actor/target candidates from currently eligible
`SpatialEntity` bindings. It evaluates a residual vector including structural
compatibility, required/suggested/anti-clue relations, semantic measurement,
identity continuity, and causal support.

Candidates are Pareto filtered and bounded. Visual similarity is a clue, not
identity and not a universal definition of the verb. A suggested
`same_outline` relation cannot exclude a differently shaped but causally
supported candidate.

### 10.2 Persistent role trajectories

The semantic goal identity excludes frame-local candidate IDs. Once a command
selects a situated pair, R2 tracks role trajectories through translation,
overlap, occlusion, and structural change. A new visual segmentation therefore
does not automatically reset accumulated goal evidence.

Identity ambiguity blocks progress authority. It does not get repaired by a
high semantic confidence score.

### 10.3 The common `SpatialEntity` interface

Both primitive regions and supported CAE composites implement the same spatial
interface. Goals and semantic schemas do not need separate logic for atomic and
composite entities.

```text
SpatialEntity
├── primitive region-binding
└── causal-entity-binding
```

## 11. Causal Entity Induction (CAE)

CAE asks which visible primitives behave as one object under intervention. It
uses settled common transformation, preserved internal relations, lineage,
coverage, contradictions, and action-conditioned transforms.

A CAE candidate can be OPEN, SUPPORTED, or REFUTED, and its identity can remain
ambiguous. Supported unique composites re-enter the ordinary role-grounding
beam as `SpatialEntity` candidates.

CAE is not semantic goal induction. A moving assembly may be a controllable
agent, a camera-relative group, a decorative animation, or an obstacle. Its
coherence establishes objecthood evidence only. Qwen may propose what that
object means; R2 and the environment must test the proposal.

Whole-scene coherent motion is treated as a possible reference-frame confound.
It does not automatically support a coupling or common-object hypothesis.

## 12. From grounded semantics to exact actions

For every grounded role tuple and exact legal command, R2 constructs an action
projection:

```text
semantic goal and schema
→ actor/target identity hypothesis
→ current potential
→ command-scoped learned actor/target effect, if supported
→ computed successor geometry
→ predicted potential after command
→ protected invariants
→ expected progress or information value
```

Opaque environment actions remain canonical. A cautious natural-language alias
may be stored only after cited transition evidence and never supplies action
authority.

### 12.1 Eligibility order

```text
PLAN_ELIGIBLE > PROGRESS_ELIGIBLE > PROBE_ELIGIBLE > INELIGIBLE
```

- `PROBE_ELIGIBLE` asks a bounded discriminating question when mechanism or
  identity is still open.
- `PROGRESS_ELIGIBLE` requires unique enough identity, a supported command
  effect, a computable successor, preserved invariants, and preferred measured
  progress.
- `PLAN_ELIGIBLE` additionally requires a bounded factorization and valid plan
  certificate. It authorizes only the first exact command.

Lexical confidence never promotes a candidate between these classes.

## 13. Planning

The planner boundary is provider-neutral and controller-neutral. Available
backends include:

- deterministic bounded best-first search;
- original one-step fallback;
- model-proposed plans checked by the same R2 validators;
- `ProspectPlanner`, which factors an OPEN environment objective into bounded
  milestones and reports a prospective route.

All backends consume immutable grounded effects and potentials. No planner can
turn its simulated successor into evidence. The real environment successor
settles the first command and invalidates the rest of the route.

## 14. Independent settlement

One transition settles several questions separately.

| Axis | Question | Positive evidence | What it does not prove |
|---|---|---|---|
| Identity | Did the same role/entity persist? | correspondence and lineage | goal relevance |
| Mechanism | Did this exact command cause the predicted change? | predecessor/successor effect match | goal validity |
| Goal frontier | Did the measured potential reach a strict new best? | real successor residual | mechanism explanation or completion |
| Semantic schema | Did a diagnostic command realize a declared dynamic or trigger a countercondition? | hypothesis-specific successor test | environment terminal |
| CAE | Did members transform coherently with preserved relations? | transition-cited common transform | semantic role or objective |
| Goal contract | Did a local terminal coincide causally with a level/score terminal? | environment terminal settlement | universal reuse |
| Environment | Did level, game, or score terminal occur? | environment API only | why it happened |

A novel command may advance a goal before its mechanism is already known. The
goal receives frontier support while the new mechanism is learned separately.
A return to an old best is local progress but does not add frontier support or
reset stagnation.

A schema hypothesis is supported only by a diagnostic observation it actually
predicted. A command that does not instantiate its declared dynamic leaves it
OPEN. This prevents generic movement from being miscounted as evidence for any
attractive semantic story.

## 15. Feedback, revision, and memory

### 15.1 Settlement-synchronous revision

Every newly settled transition creates an evidence reference. The next model
write must consume that exact reference. A response against an older basis is
rejected and cannot overwrite newer state.

### 15.2 Failed goals

Repeated uniquely grounded nonprogress can suspend a failed goal while a
focused semantic repair is pending. Learned command effects survive because a
failed goal does not refute a mechanism.

### 15.3 Supported plateaus

A goal with real progress support but no new frontier for a bounded number of
steps requests one complementary or refined hypothesis. The existing supported
goal remains available; the plateau is not mislabeled as failure. One repair is
requested per `(goal, best frontier)` epoch.

### 15.4 Level-boundary consolidation

Deep consolidation receives a completed-context digest and may propose a small
reusable abstraction. Transferred schemas lose situated bindings and empirical
support. They must bind and earn intervention evidence again in the new
context.

## 16. Runtime and Arcade surfaces

Frame parsing and schema fitting occur before the first Qwen response, so the
frame-zero request already contains the anonymous affordance frontier. After an
action, successor fitting occurs before settlement, but the UI publishes the
new frame and its settlement atomically to prevent mixed-boundary flicker.

Agent Arcade renders the exact model scratchpad separately from R2 workspace
objects, action ranking, planner projections, and CAE. Presentation traces do
not enter the canonical epistemic graph.

The runtime uses the dynamically loaded canonical scratchpad module. This is
important: importing the same source under a second module name would create
two distinct semantic globals. The frame observer and controller now publish
through the same live module and the same `r2_semantic_projection` object.

## 17. Genericity beyond one game

The architecture generalizes by interface, not by collecting more verb rules.

```text
new game/modal channel
    → add neutral observation bindings
    → optionally add a bounded affordance provider/evaluator
    → expose anonymous alternatives in the existing semantic projection
    → let Qwen name and compose them
    → compile through the same goal/schema contracts
    → ground over the same entity/action interfaces
    → settle with the same independent evidence axes
```

Examples of future provider families, none yet claimed implemented:

- temporal ordering and periodicity;
- inventory/resource conservation;
- UI widget state and interaction affordances;
- textual instruction/entity correspondence;
- score and reward change points;
- occlusion/reveal events;
- collision and reachability graphs;
- object creation, destruction, and count transitions.

Qwen is not limited to concepts named by a provider. The frontier routes
attention to measurable structure; visual and transition evidence plus Qwen's
pretrained prior may motivate a concept absent from the frontier. Such a
proposal simply starts as an uncited, zero-support measurement/schema and must
pass normal compilation and settlement.

## 18. Non-overfitting audit

The current design avoids target-game overfitting in four ways:

1. Production probes name feature algebras, not games, colors, shapes, routes,
   or desired relations.
2. Frontier entries explicitly set `semantic_label=null` and `desired=null`.
3. Opportunity references bind exact observed measurement structure, not a
   semantic word to a preferred residual.
4. Novel relation names are open, while executable dynamics remain closed and
   falsifiable.

Every production capability should have positive, ambiguous, and adversarial
tests. Translation, palette, identity, and support-scale changes must not alter
intrinsic opportunity semantics. Empty features must fail open. A cited
opportunity with one changed measurement field must be rejected.

## 20. Current verification and honest live boundary

Implemented and tested:

- one semantic projection from frame-zero observation through controller
  settlement;
- one prose semantic state with compiler-derived summary/objective;
- anonymous spatial affordance measurements with no entity IDs or semantic
  labels;
- palette/translation invariance for intrinsic opportunities;
- scale bands that retain larger alternatives when singleton relations tie;
- exact opportunity-template binding and mismatch rejection;
- open Qwen relation-family naming with closed testable dynamics;
- existing semantic-to-goal-to-entity-to-command projection and independent
  settlement;
- fail-open empty features and zero model authority.

Focused semantic/runtime tests pass. The full suite passes except the unchanged
historical-doc test whose expected
`experiments/parallel-cognitive-workspace-v1-16/artifacts/SUMMARY.json` is absent.

Fresh live AR25 produced one complete semantic-control vertical slice. Qwen
proposed `align` with a novel occupancy-to-enclosed-negative-space residual;
R2 grounded actor and target to two actual entities, admitted the OPEN schema
as probe-eligible, selected opaque `ACTION_1`, observed actor translation
`[-3,0]`, and settled the measured potential from 93 to 96. CAE retained a
seven-member OPEN composite with one action-conditioned transform. The first
probe therefore learned a mechanism but regressed the proposed goal; it was
not progress evidence.

The next Qwen update cited a frontier opportunity while changing its exact
measurement template. The provenance compiler correctly rejected it, exposing
a further interface defect: the compiler previously accepted the remaining
prose as an empty goal state. The current compiler now fails such writes
atomically, returns its diagnostic through the one R2 projection, and derives
terminal relation rather than asking Qwen to duplicate it. This establishes
that language can reach measurement, entities, action, effect learning, and
settlement. It does not establish a solved level, correct final interpretation,
or score gain; the repair still requires fresh live and cross-game
falsification.

## 21. Remaining architectural gaps

1. **Transformation-aware structural matching.** The spatial measurement
   language currently compares identity orientation. Generic rotation,
   reflection, and possibly scale hypotheses need explicit bounded transforms,
   not prompt guesses.
2. **Richer modality providers.** Current affordances are spatial. Temporal,
   resource, instruction, UI, reveal, and reward providers remain prospective.
3. **Diagnostic experiment selection.** Schema hypotheses reach commands, but
   choosing the most informative intervention across several explanations is
   still weaker than the representation path.
4. **Semantic composition quality.** Qwen can name a relation and cite a typed
   opportunity, but it still needs evidence-efficient ways to compose intrinsic
   compatibility with scene-space approach/contact and environment objectives.
5. **Terminal induction.** Local residual progress is not the same as level
   completion. Goal contracts need more environment-terminal settlements across
   structurally different games.
6. **Cross-game evidence.** No claim of broad ARC-AGI-3 competence, score gain,
   or Kaggle competitiveness follows from the current live trace.

## 22. The intended end state

The mature R2 loop should let language trickle downward without letting
language bypass evidence:

```text
Qwen imagines a high-level concept
→ names a relation and its role semantics
→ cites or proposes measurable opportunity structure
→ predicts dynamics and counterconditions
→ R2 compiles a zero-support schema
→ R2 grounds candidate entities, including induced composites
→ R2 projects the schema onto exact actions
→ R2 chooses progress or a discriminating experiment
→ the environment supports, refutes, or leaves each layer open
→ the surviving concept becomes a reusable but still defeasible schema
```

That is the architectural meaning of “Qwen natural language trickles down and
binds to the epistemic engine at all levels.” Language supplies breadth and
abduction. Typed projection supplies grounding. Causal settlement supplies
truth. Control remains narrow, explicit, and earned.
